# How to setup the Frontend and Backend:

## Initialise npm
- Change your current working directory to the frontend by typing this into the terminal, `cd FRONTEND/`.
- You will then type, `npm init -y` into the terminal to create your package.json.
- After to go directly to Backend directory, you can type, `cd ../BACKEND/` into the terminal.
- In addition to typing, `npm init -y` and `npm install --save-dev wrangler`, you will have to go into the `wrangler.toml` configs and follow the commented instructions.
